Répétitions : chaque vendredi, tous les 15 du mois, chaque premier lundi du mois, tous les 2 jours, chaque matin — la tâche revient toute seule quand vous la terminez.
Sujets : le nom d'un sujet existant suffit (tondre la pelouse maison samedi, projet X/EB rédiger l'EB) ; @Nouveau_sujet en crée un (« perso » dans la phrase le classe en Perso). avant / d'ici / pour / à rendre le fixent une échéance ; demain, lundi, le 15 fixent le jour où je m'y mets. Sans date, Dori demande quand vous le rappeler. Mots reconnus : urgent, important, prioritaire.
Gestes : glisser une tâche vers la droite = terminée, vers la gauche = demain (jamais au-delà de l'échéance) ; appui long = changer sa priorité sans ouvrir la fiche. Le micro utilise la dictée de l'iPhone. Urgence automatique à 2 jours de l'échéance ; tâches terminées gardées 90 jours.
